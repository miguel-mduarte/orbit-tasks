# Orbit Tasks

Quadro Kanban responsivo, em português, com persistência 100% local via `localStorage`. Criado como projeto demonstrativo para o portfólio PurpleRoot.

## Recursos
- Três etapas: A fazer, Em andamento, Concluído
- Criar, editar, mover e excluir tarefas
- Prioridade e descrição
- Indicadores de progresso
- Layout responsivo e acessível por teclado nos controles principais
- Sem login, sem coleta de dados e sem backend

## Executar
Abra `index.html` no navegador ou sirva a pasta com um servidor estático (`python -m http.server 8000`).

## Publicação
Site estático; publique o diretório raiz no Vercel sem comando de build.

## Limitações
Os dados ficam exclusivamente no navegador atual. Limpar o armazenamento do navegador remove as tarefas. Não há sincronização entre dispositivos.
